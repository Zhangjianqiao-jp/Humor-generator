# 对齐恢复的可识别性：目标参照可能主导结果

## 问题

当前接口计算 Z=A(H,E(P))，E(P) 是待传递计划 P 的逐 token 词嵌入。E(P) 已包含答案字段，因此从 Z 恢复 P，不能单独识别 H 的语义贡献。这不是未授权测试标签泄漏：P 本来就是合法消息；问题是如何归因研究收益。

## 一个明确的数学反例

令 H,E∈R^(N×d)，中心化后均为秩 N−1，d>N−1。记 P_N=I−11ᵀ/N，C_H=H_cᵀH_c/N，C_E=E_cᵀE_c/N。下面使用无正则、在支撑子空间上的伪逆平方根，与实际 λ=0.001 实现区分。

令 W_H=H_c C_H^(†1/2)，W_E=E_c C_E^(†1/2)。两者满足

W_H W_Hᵀ = W_E W_Eᵀ = N P_N。

因此存在正交 R 使 W_H R=W_E（相同 Gram 矩阵的点集可通过正交变换对应）。因 d>N−1，可在未被消息占用的补空间调整符号，令 det R=+1 而不改变消息映射。于是

W_H R C_E^(1/2)+μ_E = E。

H 可以是与 E 独立生成的随机矩阵，也能重建 E。若再统一范数并做最近词表锚定，结果仍可由参照内容主导。因此“随机状态也可能恢复目标嵌入”是反对单凭恢复指标证明源状态语义的重要反例。

这不是对所有输入的定理：实际计划有重复 token，E 可能不满足满行中心化秩；实际还有正则、词表锚定及有限精度。该反例足以说明逻辑蕴涵不成立，但不能替代真实 Qwen 控制实验，也不能否定 StateBridge 的经验结果。

## 独立可执行检查

`scripts/audit_alignment_reference_fit.py` 用三个固定种子、N=8、d=32 的独立随机 H/E 验证上述精确反例；并调用当前 λ=0.001、α=0 模块记录重着色后的参照 RMSE。只使用小 CPU 矩阵；结果在 `alignment_reference_fit_audit.json`。这是方法可识别性检查，不是模型质量或精度优化实验。

## 必须增加的机制对照

现有已排队 7106405 保持不变。后续另立版本，同样本、相同长度和相同 E(P)，比较：

1. A(H,E(P))：真实 hidden。
2. A(G,E(P))：独立随机 G，范数/尺度匹配，随机种子固定，不含消息语义。
3. A(ΠH,E(P))：打乱 hidden 的 token 行但保留目标 token 顺序，并重新拟合对齐；检验目标参照能否修复错配。
4. 直接 E(P) 与同范数 E(P)：检验额外变换相对简单文本接口的必要性。

若随机或打乱源状态仍有相近恢复率，应将恢复解释为目标参照驱动，不能宣称保留源 hidden 的专有信息。要进一步证明 H 的增量价值，需要在相同 E(P) 下改变有意义的 H 上下文，观察稳定的内容或任务收益；目前从同一 P 回放得到 H=f(P) 本身没有文本之外的新信息。

这组对照只检验机制，不替代幽默盲评。即便真 hidden 优于随机，也不自动证明优于强文本生成基线。
