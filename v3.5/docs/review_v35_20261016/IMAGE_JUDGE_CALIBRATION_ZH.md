# 原图 vs 自动描述：同候选评审校准

同五个当前训练集人工排序候选、同一模型、temperature=0、maxTokens=256、两种顺序，仅将 grounding 证据和对应提示措辞从描述换为原图。图像模式不同时发送描述，避免两类证据混淆。使用原始 JPEG，记录逐图 SHA256，不裁剪或重绘。

| 校准指标 | 描述条件 | 原图条件 |
|---|---:|---:|
| 选中人工高分 caption 的展示次数 | 6/10 | 7/10 |
| 顺序一致的候选对 | 3/5 | 4/5 |
| 相同 caption 判平局 | 2/2 | 2/2 |
| JSON 格式有效 | 12/12 | 12/12 |

这里只有五对独立内容，不能宣称 10 个独立样本的准确率，更不能由 +1 次一致推断显著改善。原图仍有一对两种顺序都选人工低分 caption（nycc_593），一对顺序反转（nycc_549）。人工均分不是绝对真值，评审有不同审美的可能；同样不能为了匹配排名反复调这五题。

决策：补原图没有充分解决评审可靠性问题。不扩大当前自动评分为最终质量结论；后续可以把图像评审作为辅助信号，但正式方法判断仍缺独立人工偏好/更广泛的留出校准及顺序复核。训练集小试没有验证 test 泛化。

脚本 `scripts/judge_interface_images.py` 与描述版分开，默认只离线校验；对所有待发送图像验证 JPEG、尺寸及文件大小，记录哈希。补入原工作区已有的 `run_homer_bedrock.py`，修复 PR 中评审脚本依赖缺失；该模块只读本地凭证，不把凭证写入记录。实际 12 次请求均完成，结果摘要见 `image_judge_calibration_validation.json`。原始图像、候选和私有映射不提交公开 PR。

对齐扩展作业 7106405 仍排队，本轮未重复提交或改动其代码。

参考：[Zheng et al., NeurIPS 2023](https://arxiv.org/abs/2306.05685)，关于 LLM 评审偏差；[AWS ImageSource](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_ImageSource.html)，图像字节接口。此处可靠性判断依据本项目真实对照数据，不依赖论文保证。
