# 接口实验的幽默盲评准备

已有前三批真实 GPU 输出生成本地审阅包：`results/preflight/v35_effectiveness_20261017/blind_partial12/`。12 个训练 cluster、每图两个种子，三类配对，共 72 对；每对交换顺序，共 144 个独立展示条目。所有评分均为 null，尚未调用评审 API、没有质量结果。

配对：文本计划 vs 无计划、soft replay vs 文本计划、norm hidden vs 文本计划。exact embeddings 已用于接口一致性控制，不重复纳入方法优劣排名。caption 独立于 explanation 展示；不展示计划或方法标签。review.jsonl 给评审，private_key.jsonl 保留给分析者。内容本身可能透露风格，因此隐藏方法标签不意味着完美盲法。

## 规则与数学口径

分别评幽默偏好和描述一致性；允许 tie、unjudgeable、uncertain。无效格式不自动算幽默负例，也不静默排除：作为不可评价保留并报告覆盖率。描述不是原图，故本包不等于 HOMER 官方图像评价。

同一配对的两种展示顺序映射回方法后，只有一致的 A 胜/B 胜/tie 才记为稳定判定，否则记为顺序不一致、待复核，不能按有利方向挑选。对稳定配对，候选方法胜记 1、平记 0.5、负记 0。每个 cartoon 内先对种子平均，再跨 cartoon 平均；bootstrap 以 cartoon 为单位，不把同一图的种子或顺序当作独立样本。这里最多是 12 个独立图级单位，不是 144 个。

对于一项比较，总配对数 N，已稳定判定分数之和 S，不可评价或顺序不一致数 U：完整总体平均偏好分在 [S/N, (S+U)/N] 内。这是缺失结果取 0 或 1 的最坏情况界限，不是置信区间；已判定子集的 S/(N-U) 必须同时报告覆盖率，不能单独用于宣称总体胜利。各 cartoon 若配对数不等，应先在图内构造界限再平均。

训练集探索结果只用于决定下一步，不作为论文独立测试结论。文本计划是否优于 no-memory 尚未得到质量证据；不能从两者生成不同文本推导质量改善。完整对齐即便恢复计划，也仍须过这个质量门槛。
